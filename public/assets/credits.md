# Café Timelapse — Asset Credits

All assets used in this project must be license-cleared (CC0, CC-BY, or original)
and recorded below before inclusion in the build.

## Schema

| Path | License | Source | Notes |
|------|---------|--------|-------|
| _(example)_ `public/assets/textures/wood-floor.png` | CC0 | ambientCG.com | Oak planks, 2K resolution |

## Rules

1. **No asset ships without a row in this table.**
2. **Accepted licenses:** CC0, CC-BY 3.0, CC-BY 4.0, or original work created for this project.
3. **Attribution** must be included in the Source column for CC-BY assets.
4. **Procedurally generated textures** (canvas-based, created in code) are original work and do not require a row, but note the generator file in Notes if you want.
5. **Music and SFX** must also be listed here with their license and source.
